# kream-reresell

KREAM 랭킹 상품을 훑어서, 빠른배송 수요가 충분하고 마진이 나는 상품에
**일반배송(창고 보관) 구매 입찰**을 자동으로 넣는 프로그램.

## 판단 규칙

1. 랭킹 → 상품군(기본 `가방`) → 순위대로 상품을 본다. 신발류는 하지 않는다.
2. 상품 페이지 "거래 내역 더보기" 에서 **최근 30일 빠른배송(⚡) 체결 건수** 를 센다. 15건 미만이면 건너뛴다.
3. 구매하기 모달에서 **빠른배송 가격 = A** (내가 팔 예상가, 95점 가격은 무시).
4. 일반배송 → "즉시 구매 / 구매 입찰" → 구매 페이지의 **즉시 판매가 = B**.
5. `A - B > A × 10%` 일 때만 입찰.
6. 구매 입찰 탭에서 희망가 **B**, 마감기한 **7일**, 구매 입찰 계속.
7. 배송방법 **창고 보관** (선택 확인이 안 되면 절대 진행하지 않음), 포인트 있으면 최대 사용, 결제 카드는 그대로.
8. 입찰하기 → 확인 항목 3개 체크 → 입찰하기 → "구매 입찰이 완료되었습니다" 확인 → 탭 닫기.

숫자(30일 / 15건 / 10% / 7일 / 상품 수)는 `.env` 에서 바꾼다.

건너뛰는 경우: 체결 거래 표가 없는 상품(아직 리셀 거래가 열리지 않음 - 매 실행마다 다시 확인한다),
옵션(사이즈)이 있는 상품, 빠른배송 판매자가 없는 상품, 이미 입찰한 상품(`data/bids.json`).

속도: 이미지/동영상/폰트를 받지 않는다(`.env` `BLOCK_IMAGES=0` 으로 끌 수 있다). 상품 하나에 약 10초.

## 설치

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
```

브라우저는 설치된 크롬을 그대로 쓴다 (`auth/chrome_profile_kream` 프로필, 창이 보이는 상태로 실행).
로그인은 프로필에 유지되고, 세션이 끊기면 `.env` 의 `KREAM_ID`/`KREAM_PW` 로 이메일 자동 재로그인한다
(`/login/email` 폼, 캡차 없음 - 2026-09-03 확인). 비밀번호를 비워두면 크롬 창에서 직접 로그인할 때까지 5분 기다린다.

## 실행

```
.venv\Scripts\python scripts\run.py --category 가방 --dry-run     # 판단만 (입찰 안 함)
.venv\Scripts\python scripts\run.py --category 가방               # 조건 맞으면 실제 입찰
.venv\Scripts\python scripts\run.py --category 가방 --limit 10
.venv\Scripts\python scripts\run.py --product 385408 --force --stop-before-submit --inspect
```

- `--dry-run` : 거래량/마진 판단까지만 하고 입찰 폼은 건드리지 않는다.
- `--stop-before-submit` : 입찰 화면을 다 채우되 마지막 "입찰하기" 는 누르지 않는다.
- `--force` : 거래량/마진 조건을 무시한다 (화면 점검용).
- `--inspect` : 화면마다 `dumps/` 에 스크린샷 + 접근성 트리를 남긴다.
- `--product ID ...` : 랭킹 대신 지정한 상품만 본다.

## 바탕화면에서 실행

바탕화면의 **`KREAM 자동입찰`** 바로가기를 더블클릭하면 창(`scripts/gui.pyw`)이 뜬다.
상품군·상품 수·모드(실제 입찰 / 판단만)를 고르고 [실행]. 진행 상황이 창에 표시되고,
[중지]를 누르면 지금 보는 상품까지만 처리하고 멈춘다. 끝나면 결과 요약과 보고서 경로를 알려준다.

상품군/개수는 .bat 파일을 메모장으로 열어 `--category 가방 --limit 30` 부분을 고친다.

## 결과

- **엑셀 보고서**: `바탕화면\KREAM 결과\KREAM 입찰결과 YYYY-MM-DD HHMM.xlsx` - 실행이 끝나면 저장된다 (자동으로 열지 않음, `--open` 을 주면 연다).
  상품마다 판정(입찰완료/입찰대상/건너뜀/중단/오류/확인필요), 사유, 30일 빠른배송 건수, A, B, A−B, 마진율, 입찰가, 링크.
  저장 위치를 바꾸려면 `.env` 에 `REPORT_DIR=경로`.
- `data/bids.json` : 입찰한 상품 (같은 상품에 다시 입찰하지 않는다)
- `data/run_log.csv` : 본 상품마다 거래량 / A / B / 결과 (누적)
- `logs/run_*.log` : 실행 로그
- 프로그램이 중간에 죽어 보고서가 안 만들어졌으면 `python scripts/report_from_log.py` 로 마지막 실행분을 엑셀로 만든다.
